# اجتماع شباب ثانوي — الكنيسة الرسولية ريدة

تطبيق أندرويد لحضور الاجتماع بالنقاط، صور الاجتماع، المواعيد والأنشطة، و"اكسب نقاط".

- الـ APK بيتبني لوحده مع كل تعديل (تبويب Actions) وبيتنشر في Releases.
- بيانات Firebase في `android/app/src/main/assets/www/config.js`.
- قواعد الأمان في `firestore.rules` (تتنسخ في Firestore → Rules).
